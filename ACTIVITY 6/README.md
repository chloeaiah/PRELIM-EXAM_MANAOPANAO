## 📌 Activity Description

For this activity, I created **Petal Parcel**, a website developed using **Replit**. The project allowed me to explore website development and apply my creativity in designing a digital platform.

Through this activity, I experienced how an idea can be transformed into a website using coding and an online development environment. It also helped me understand the process of creating and organizing website elements to achieve a cohesive design.

## 🌸 What Have I Learned?

Through this activity, I learned how to use Replit as an online platform for developing a website. I gained experience in organizing website content, understanding basic web development, and applying design concepts to create a digital output.

I also learned that website development requires both creativity and technical skills. A website should not only look visually appealing but should also be organized and easy to navigate.

---

## 🧩 Challenges & Solutions

One of the challenges of creating a website was translating my design ideas into an actual digital platform. I needed to consider the arrangement of elements, the overall appearance, and the organization of the website.

Using Replit allowed me to work on the project in an online coding environment and make adjustments as I developed the website.

---

## 🚀 Future Applications

The skills I gained from this activity can be useful in future academic and professional projects. As a Civil Engineering student, I can apply website development skills to create digital portfolios, project presentations, information platforms, and other online resources.

This activity also encouraged me to explore how technology can be used to communicate ideas and present information creatively.

---

## 🎨 Creative Process & Design Choices

The project was centered around the concept of **Petal Parcel**, with a floral-inspired identity. I aimed to create a website that reflects the name and concept through its overall visual presentation.

I used Replit as my development platform, combining technical implementation with creative design decisions to turn the concept into a website.
